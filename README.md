A lightweight, high-performance, standalone Fabric mod providing first-class native Wayland support and low-latency SDL3 windowing optimizations for Minecraft on Linux.

Zero bloat, zero unnecessary client dependencies — purely focused on system-level Linux integration and compositor ergonomics.

---

## Features

- **Early SDL3 Wayland Bootstrap**: Enforces native Wayland display scaling (`SDL_HINT_VIDEO_WAYLAND_SCALE_TO_DISPLAY = "1"`), double-buffering, and server-side decoration preference before the window or graphics context are initialized.
- **Desktop Application Metadata & Grouping**: Correctly registers Wayland `app_id` as `minecraft` and injects `SDL_SetAppMetadata` properties. Ensures your desktop environment (COSMIC, GNOME, KDE, Hyprland) groups Minecraft windows properly on the dock and taskbar.
- **1px Borderless Fullscreen Gap Fix**: Eliminates the legacy Windows DWM 1-pixel frame padding on Wayland compositors that causes transparent edge slits.
- **Focus Grab & Confinement Recovery**: Automatically re-asserts cursor confinement and keyboard grabs upon window focus regain so hotkeys never leak out during gameplay.
- **Primary Selection Clipboard Synchronization**: Seamlessly synchronizes text between Minecraft and Linux primary selection buffers (`SDLClipboard.SDL_SetPrimarySelectionText` / `SDL_GetPrimarySelectionText`) allowing standard terminal/middle-click paste workflows.
- **Wayland IME Input Sanitization**: Suppresses raw non-printable control characters (`< 32`) generated by Wayland input methods from leaking into chat and text boxes.
- **Async Page Flip / Tearing Protocol**: Optional toggle for `wp_tearing_control_v1` async page flips via `SDL_GL_SetSwapInterval(0)` on supported Wayland compositors for minimum latency.
- **Smooth Relative Mouse Motion**: Eliminates synthetic cursor centering warps and bypasses OS acceleration lag.
- **In-Game ModMenu Configuration Screen**: Tweak every setting in real time with persistent JSON storage in `config/sdl-wayland-tweaks.json`.

## Installation

1. Install [Fabric Loader](https://fabricmc.net/) for Minecraft 26.3.
2. Download the latest jar from the [Releases](https://github.com/Den1zzDev/sdl-wayland-tweaks/releases) page.
3. Place `sdl-wayland-tweaks-26.3-1.0.0.jar` into your Minecraft `.minecraft/mods` directory (or PrismLauncher / Modrinth App mods list).
4. Launch the game using your native Wayland environment.

---

## Configuration

You can configure SDL Wayland Tweaks directly in-game via **ModMenu** or by editing `.minecraft/config/sdl-wayland-tweaks.json`:

```json
{
  "waylandHints": true,
  "appMetadata": true,
  "fixBorderlessPadding": true,
  "focusGrabRecovery": true,
  "imeControlCharFiltering": true,
  "primarySelectionSync": true,
  "asyncPageFlip": false,
  "relativeMouseOptimizations": true,
  "bypassOsScale": true,
  "bypassCompositor": true,
  "preventMinimizeOnFocusLoss": true,
  "focusClickthrough": true,
  "motionDeltaAccumulation": true
}
```

## Building from Source

Requires **JDK 25** (such as OpenJDK 25 or Eclipse Temurin 25):

```bash
git clone https://github.com/Den1zzDev/sdl-wayland-tweaks.git
cd sdl-wayland-tweaks
./gradlew assemble
```

The resulting jar will be in `build/libs/`.
